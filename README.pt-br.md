<h1>Estudo Sobre Objetos JavaScript</h1>
<p>This README is also available in <a href="./README.md">English</a>.</p>
<p>Este projeto é um estudo completo sobre objetos JavaScript com exemplos detalhados e explicações sobre criação de objetos, encapsulamento, herança e polimorfismo.</p>
<h2>Visão Geral do Projeto</h2>
<p>O código demonstra diferentes formas de criar objetos em JavaScript, uso de funções construtoras, técnicas de encapsulamento com propriedades privadas, herança entre construtores, polimorfismo por meio de sobrescrição de métodos, além da verificação de tipos de dados e instâncias.</p>
<h2>Funcionalidades</h2>
<ul>
  <li>Criação de objetos usando literais e funções construtoras</li>
  <li>Encapsulamento de propriedades privadas com getters e setters</li>
  <li>Herança de propriedades e métodos entre construtores</li>
  <li>Polimorfismo com sobrescrição de métodos em subclasses</li>
  <li>Verificação de tipos de dados e instâncias usando <code>typeof</code> e <code>instanceof</code></li>
  <li>Comentários claros e explicativos ao longo do código</li>
</ul>
<h2>Tecnologias Utilizadas</h2>
<ul>
  <li>JavaScript (sintaxe ES5)</li>
</ul>
<h2>Uso</h2>
<p>Execute o arquivo <code>main.js</code> usando Node.js ou qualquer ambiente JavaScript para ver os exemplos e as saídas no console.</p>
