<h1>JavaScript Objects Study</h1>
<p>Este README também está disponível em <a href="./README.pt-br.md">Português</a>.</p>
<p>This project is a comprehensive study of JavaScript objects with detailed examples and explanations on object creation, encapsulation, inheritance, and polymorphism.</p>
<h2>Project Overview</h2>
<p>The code demonstrates different ways to create objects in JavaScript, usage of constructor functions, encapsulation techniques with private properties, inheritance between constructors, polymorphism through method overriding, and checking data types and instances.</p>
<h2>Features</h2>
<ul>
  <li>Object creation using literals and constructor functions</li>
  <li>Encapsulation of private properties with getters and setters</li>
  <li>Inheritance of properties and methods between constructors</li>
  <li>Polymorphism with method overriding in subclasses</li>
  <li>Verification of data types and instances using <code>typeof</code> and <code>instanceof</code></li>
  <li>Clear and explanatory comments throughout the code</li>
</ul>
<h2>Technologies Used</h2>
<ul>
  <li>JavaScript (ES5 syntax)</li>
</ul>
<h2>Usage</h2>
<p>Run the <code>main.js</code> file using Node.js or any JavaScript environment to see the examples and console outputs.</p>
